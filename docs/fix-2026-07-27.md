# Correção de compilação — 27/07/2026

Foram corrigidos erros de importação detectados pelo `mvn clean package` durante o build com Podman:

- `Components` passou a ser importado de `io.swagger.v3.oas.models.Components`.
- `DisabledException` passou a ser importado de `org.springframework.security.authentication.DisabledException`.
- `AuthenticationException` passou a ser importado de `org.springframework.security.core.AuthenticationException`.
- `PageableDefault` passou a ser importado de `org.springframework.data.web.PageableDefault` nos controllers que usam paginação.

Para reconstruir:

```powershell
podman compose down --remove-orphans
podman compose build --no-cache backend
podman compose up --build -d
podman compose logs -f backend
```
